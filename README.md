# 🍽️ Landing Page para Restaurante

Uma landing page moderna e responsiva desenvolvida para um restaurante, com o objetivo de apresentar seus produtos, fortalecer a identidade visual da marca e proporcionar uma experiência agradável aos visitantes.

O projeto foi desenvolvido utilizando apenas **HTML5, CSS3 e JavaScript**, priorizando desempenho, design moderno, responsividade e uma navegação intuitiva em qualquer dispositivo.

---

## 🚀 Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript (Vanilla)
* Google Fonts

---

## ✨ Funcionalidades

* 🍽️ Apresentação institucional do restaurante
* 📖 Seção de cardápio ou produtos
* 📸 Galeria de imagens
* 📱 Layout totalmente responsivo
* 🎨 Interface moderna e intuitiva
* ✨ Animações suaves durante a navegação
* ⚡ Alto desempenho e carregamento otimizado
* 🌙 Suporte a tema claro e escuro
